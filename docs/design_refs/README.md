# Design References — Índice

> Documentos visuais de referência para o design do Capibraba. Este diretório
> é o conteúdo persistente e editável por trás do plugin **Game Design Ref**
> (o painel na interface). Cada arquivo é autônomo — leia o que precisar.
>
> Fontes fundamentais que orientam tudo aqui:
> - **Theory of Fun for Game Design** — Raph Koster
> - **The Art of Game Design: A Book of Lenses, 3ª ed.** — Jesse Schell
> - **Game Maker's Toolkit (GMTK)** — Mark Brown

## Como usar

- **Design de mecânicas/loop de itens** → `game-design.md`.
- **Arena topdown (mirar, tileset, legibilidade)** → `pixel-art-topdown.md`.
- **Arena plataforma (pulo, plataformas, contraste)** → `pixel-art-plataforma.md`.

> Para reaproveitar entre múltiplos workspaces, copie este diretório (ou linke-o)
> para qualquer projeto. O conteúdo é genérico — não é específico do Capibraba.
